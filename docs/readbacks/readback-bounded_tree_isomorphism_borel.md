Let $S=\mathbb N^{<\omega}$ be the set of all finite lists of natural numbers, including the empty list, and let $\mathcal T$ consist of all Boolean functions $T:S\to\{\mathrm{false},\mathrm{true}\}$ satisfying $T(s^\frown[n])=\mathrm{true}\Rightarrow T(s)=\mathrm{true}$ for every list $s$ and every $n\in\mathbb N$. Give $\{\mathrm{false},\mathrm{true}\}^S$ its product topology with discrete Boolean coordinates, give $\mathcal T$ its subspace topology, and equip $\mathcal T$ with the Borel sigma algebra of that topology. For $T\in\mathcal T$, write $N_T=\{s\in S:T(s)=\mathrm{true}\}$ for its actual set of nodes and say that $s$ is an immediate child of $t$ precisely when $s=t^\frown[n]$ for some $n\in\mathbb N$. Let $C_a$ be the subtype of all $T\in\mathcal T$ for which there exists a function $\rho:N_T\to\operatorname{Ord}$, with values in the same small-universe ordinals as $a$, such that $\rho(s)<a$ for every node $s$, and $\rho(s)<\rho(t)$ whenever $s$ is an immediate child of $t$. The function $\rho$ is existentially quantified separately for each tree; it is not extra chosen data in an element of $C_a$, and no least or canonical rank function is specified. Equip $C_a$ with the sigma algebra induced from the Borel sigma algebra of $\mathcal T$ by the inclusion $C_a\hookrightarrow\mathcal T$, namely the sets of the form $C_a\cap B$ for Borel $B\subseteq\mathcal T$. The conclusion is that the set $G_a\subseteq C_a\times C_a$ of all pairs $(T,U)$ for which there exists a bijection $e:N_T\to N_U$ satisfying, for every ordered pair of nodes $s,t\in N_T$, $s=t^\frown[n]$ for some $n\in\mathbb N$ if and only if $e(s)=e(t)^\frown[m]$ for some $m\in\mathbb N$, belongs to the product of these two induced sigma algebras. Thus one bijection must preserve and reflect the immediate-child relation for all node pairs; the numerical entries appended to form children need not be preserved, and the existential bijection may depend on the pair $(T,U)$. There are no additional quantified spaces, external measurable-space choices, or hypotheses on $a$ beyond $a<\omega_1$; in particular $a=0$, finite successors, and countable limit ordinals are included. The rank convention is the displayed strict bound on every node label, with children strictly below parents: leaves may receive label $0$, the empty tree is allowed for every $a$ because all requirements on nodes are vacuous, and the one-node tree can receive label $0$ exactly when $0<a$ (so it is included at $a=1$). At $a=0$ only the empty tree belongs to $C_a$; at $a=1$ only the empty tree and the tree whose sole node is the empty list belong to $C_a$. A chain with $k$ nodes is admitted exactly when the finite ordinal $k$ is at most $a$. In the usual convention using the least well-founded node rank $r$, assigning a leaf rank $0$, and defining tree height as $\sup\{r(s)+1:s\in N_T\}$ with supremum $0$ for the empty set, the empty and one-node trees have heights $0$ and $1$, respectively; the actual condition in the declaration remains the existence of the function $\rho$ above. Every nonempty prefix-closed tree contains the empty list, so its root is present without a separate root datum; a child-preserving and child-reflecting bijection necessarily sends this root to the root. There is no requirement that the tree be infinite, have bounded finite branching, or contain every possible child; infinite node sets are allowed when the stated ordinal labeling exists, while an infinite descending chain of child ranks is excluded. The empty tree is isomorphic to itself and cannot be isomorphic to a nonempty tree, because a bijection of their actual node sets would not exist.
