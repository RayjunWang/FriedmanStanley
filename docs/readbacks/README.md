# Statement and source review

These nine blind read-backs were prepared from the exact mission statements
and their definition imports before the proof work. They explain the literal
Lean propositions, quantifier order, measurable structures, and edge cases.
Their references to placeholder proofs describe that earlier statement-review
stage; the complete proofs now belong to `Solutions/`.

`source-semantic-audit.md` separately compares the formal statements with the
supplied manuscript and the original Friedman–Stanley tree conventions. The
tree comparison asserts cofinality and does not identify identical ordinal
indices across conventions.

All ten reports were copied unchanged from the proposal-review artifacts.
Their role is semantic review of the statements. Kernel proof verification and
server acceptance are documented separately in `../verification.md` and
`../prove2me-acceptance.json`.
